Score Methodology

Composite score = NDVI anomaly (30%) + conflict density (35%) + displacement flow (25%) + rainfall deviation (10%). Each signal is normalised 0–100. Null signals are excluded and weights are redistributed proportionally. Phase thresholds: 0–20 = Phase 1, 21–40 = Phase 2, 41–60 = Phase 3, 61–80 = Phase 4, 81–100 = Phase 5.
